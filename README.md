Deloitte Australia Data Analytics Job Simulation
📖 About the Project
This repository contains my work completed as part of the Deloitte Australia Data Analytics Job Simulation program. The project demonstrates skills in data analysis, data classification, visualization using Tableau, and forensic technology through two main tasks.

🧩 Project Tasks
Task 1: Factory Telemetry Analysis
Analyzed telemetry data from Daikibo's four global factories to identify:

Which location experienced the most machine breakdowns

Which types of machines broke most frequently in the problematic location

Process:

Imported JSON telemetry data into Tableau

Created a calculated measure field "Unhealthy" with a value of 10 for each unhealthy status

Developed interactive visualizations showing downtime by factory and device type

Configured a dashboard with filtering capabilities to enable deeper analysis

Task 2: Employee Equality Classification
Analyzed and classified employee compensation data to identify potential equality issues:

Created a classification system for equality scores

Categorized scores into three groups: Fair (±10), Unfair (<-10 AND >10), and Highly Discriminative (<-20 AND >20)
